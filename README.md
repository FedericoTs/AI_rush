# AI RUSH

> A 5-minute gauntlet of AI-generated user interfaces that hate you.

You have **five minutes**. You are shown a series of ordinary-looking forms — a
password field, an OTP box, a phone number input, a cookie banner. Each one has
been generated by an AI that has seen a million UIs and understood none of them.

The password field works. You just have to play an endless runner to collect the
letters, in order, and one wrong letter starts you over.

Solve it, or skip it. The clock does not stop either way. When it hits zero your
score is stamped onto a global leaderboard of X.com handles, your row slams up
from the bottom of the screen, and you get a share card describing exactly which
interface killed you.

## Decisions already made

- **Levels are hand-authored**, written to *look* AI-generated. Deterministic,
  testable, funny on purpose. Runtime LLM generation is explicitly not v1.
- **Identity is a typed `@handle`**, no auth wall. Schema is shaped so real X
  OAuth verification can be added later without a migration.
- **Every input a human has is fair game**: touch, multi-touch, mouse, keyboard,
  gyroscope, accelerometer, microphone, camera, haptics, speakers, orientation,
  clipboard, gamepad.
- **Mobile is a first-class target**, not a responsive afterthought. PWA first,
  Capacitor wrapper after.
- **Anyone can submit a level idea**, from the end of their very first run.
  Ideas are perishable, so intake ships with the leaderboard in Phase 3 — long
  before the gallery that shows them off.
- **Agents can play too**, over MCP, in a mode where the point isn't their
  score. It's watching them confidently explain a wrong theory about a red
  Continue button.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript strict · Tailwind v4 ·
Zustand · Vitest · Playwright · Supabase (Postgres) · Vercel · MCP

Two deviations from the plan, both deliberate. **Next 16, not 15** — it was
stable by the time the scaffold went in. **CSS Modules rather than Tailwind
utilities for levels and the slop system** — brass dial gradients, fader
tracks and canvas containers are miserable as utility strings, and the slop
design system is bespoke by definition. Tailwind stays for page and layout
work.

### The level sandbox

A level is a pure function of its props, and ESLint enforces it on
`src/levels/**`:

- `Math.random()`, `Date.now()` and `new Date()` are errors. A level takes an
  `rng` seeded from `(runSeed, levelId)`, because a seed link that does not
  reproduce a run exactly is a lie.
- Importing the run store or the router is an error. Levels receive
  `onSolve` / `onFail` and never reach back into the run.
